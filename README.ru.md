# Бұл кім? — первые слова на казахском

**Открыть: https://realadilet.github.io/bul-kim/** · [Қазақша](README.md)

Интерактивная страница для малышей (2–4 года). На экране животное, член семьи, еда или предмет.
Ребёнок нажимает на картинку — голос называет её по-казахски («Мысық!»), а потом звучит голос
самого животного. Вместо YouTube: без рекламы, без перехода на чужие видео, работает офлайн.

## Разделы

- **Жануарлар** (животные) — 49 животных, у большинства свой звук
- **Отбасы** (семья) — ата, әже, әке, ана, аға, әпке, бөпе
- **Тағам** (еда) — алма, банан, нан, сүт, су, тамақ, ботқа…
- **Заттар** (вещи) — қасық, доп, көлік, пойыз, кітап, телефон… (машина, поезд, телефон со звуком)
- **Ойын** (игра) — «Мысық қайда?»: найти нужную картинку из трёх. Правильно — салют, «Жарайсың!»
  и звёздочка. Неправильно — картинка называет себя, вопрос повторяется.

## Управление

| Действие | Что происходит |
|---|---|
| картинка появилась | тишина и «?» — ребёнок может подумать и назвать сам |
| нажать на картинку | «?» превращается в слово, голос называет, потом звук животного |
| свайп / большие стрелки | следующая / предыдущая (пока идёт озвучка — не листается) |
| ★ | игра по текущему разделу |
| ▶ | автопоказ: 3 сек тишины, потом имя дважды, потом следующая |
| ▦ | все картинки раздела |
| ⛶ / ⌂ | полный экран / главное меню |

Если во время озвучки много раз нажимать на картинку, звук не перезапускается, а доигрывает до конца.

## Советы родителям

- **Добавьте на главный экран** (Safari → «Поделиться» → «На экран Домой»; Chrome → «Установить приложение»).
  Без адресной строки, после первого запуска работает без интернета.
- Чтобы ребёнок не вышел из приложения: iPhone/iPad — **Гид-доступ** (Настройки → Универсальный доступ),
  Android — **Закрепление экрана**.
- Нет звука на iPhone — проверьте переключатель беззвучного режима и громкость.

## Добавить или поменять слово

1. Найдите эмодзи на <https://googlefonts.github.io/noto-emoji-animation/> (код вида `1f412`).
2. Добавьте строку в нужный раздел `content.json`:
   ```json
   { "id": "shoshqa", "kk": "Шошқа", "ru": "свинья", "emoji": "1f416", "anim": true, "sound": false }
   ```
3. Скачайте картинку и сгенерируйте озвучку (нужен ffmpeg):
   ```bash
   pip install edge-tts
   python3 tools/build_assets.py                     # только новое
   python3 tools/build_assets.py --only qoi --force  # переозвучить одно слово
   ```
4. Звук животного: положите `assets/sounds/<id>.mp3` и запустите `python3 tools/build_sounds.py` —
   он сам поставит `"sound": true`. Источники звуков с Wikimedia Commons записаны в `tools/sounds.json`.
5. Свой голос: замените `assets/audio/<id>.mp3` (например, голосом мамы).
6. Commit + push — GitHub Pages обновится сам.

Локально: `python3 -m http.server 8000` → <http://localhost:8000>
