# Бұл кім? — алғашқы сөздер қазақша

**Ашу: https://realadilet.github.io/bul-kim/** · [Орысша / По-русски](README.ru.md)

Кішкентай балаларға (2–4 жас) арналған интерактивті бет. Экранда жануар, отбасы мүшесі, тағам
немесе зат пайда болады. Бала суретті басқанда дауыс оның атын қазақша айтады — «Мысық!» —
содан кейін жануардың өз дыбысы естіледі. YouTube-тың орнына: жарнамасыз, басқа видеоға
өтіп кетпейді, интернетсіз де жұмыс істейді.

## Бөлімдер

- **Жануарлар** — 49 жануар, көбінің өз дыбысы бар (мысық, ит, сиыр, жылқы, қой, түйе…)
- **Отбасы** — ата, әже, әке, ана, аға, әпке, бөпе
- **Тағам** — алма, банан, нан, сүт, су, тамақ, ботқа…
- **Заттар** — қасық, доп, көлік, пойыз, кітап, телефон… (көлік, пойыз, телефонның дыбысы бар)
- **Ойын** — «Мысық қайда?»: үш суреттің ішінен дұрысын табу. Дұрыс болса — салют, «Жарайсың!»
  және жұлдыз. Қате болса — сурет өз атын айтады да, сұрақ қайталанады.

## Қалай ойнайды

| Әрекет | Не болады |
|---|---|
| сурет шыққанда | үнсіз, астында «?» — бала өзі ойланып, атын айтып көрсін |
| суретті басу | «?» сөзге айналады, дауыс атын айтады, сосын жануардың дыбысы |
| солға / оңға сырғыту, үлкен көрсеткілер | келесі / алдыңғы сурет (дауыс біткенше ауыспайды) |
| ★ | осы бөлім бойынша ойын |
| ▶ | автоматты көрсету: 3 секунд үнсіз, сосын аты екі рет, сосын келесісі |
| ▦ | бөлімдегі барлық суреттер |
| ⛶ / ⌂ | толық экран / басты бет |

Дауыс айтылып жатқанда суретті қайта-қайта басса, дыбыс басынан қайталанбайды — соңына дейін ойнайды.

## Ата-аналарға кеңес

- **Басты экранға қосыңыз** (Safari → «Бөлісу» → «Басты экранға»; Chrome → «Қолданбаны орнату»).
  Мекенжай жолағы болмайды, бір рет ашқаннан кейін интернетсіз жұмыс істейді.
- Бала беттен шығып кетпеуі үшін: iPhone/iPad — **Guided Access** (Settings → Accessibility),
  Android — **Screen pinning**.
- iPhone-да дыбыс шықпаса — дыбыссыз режим ауыстырғышын және дыбыс деңгейін тексеріңіз.

## Сөз қосу немесе өзгерту

1. Эмодзиді табыңыз: <https://googlefonts.github.io/noto-emoji-animation/> (код — `1f412` сияқты).
2. `content.json` ішіндегі керек бөлімге жол қосыңыз:
   ```json
   { "id": "shoshqa", "kk": "Шошқа", "ru": "свинья", "emoji": "1f416", "anim": true, "sound": false }
   ```
3. Суретті жүктеп, дауысты жазыңыз (ffmpeg керек):
   ```bash
   pip install edge-tts
   python3 tools/build_assets.py                     # тек жаңаларын
   python3 tools/build_assets.py --only qoi --force  # бір сөзді қайта жазу
   ```
4. Жануардың дыбысы: `assets/sounds/<id>.mp3` файлын салыңыз да, `python3 tools/build_sounds.py`
   іске қосыңыз — ол `"sound": true` белгісін өзі қояды. Wikimedia Commons-тан алынған дыбыстардың
   дереккөзі `tools/sounds.json` ішінде.
5. Өз дауысыңызды қойса болады: `assets/audio/<id>.mp3` файлын ауыстырыңыз (мысалы, ананың дауысы).
6. Commit + push — GitHub Pages өзі жаңарады.

Жергілікті іске қосу: `python3 -m http.server 8000` → <http://localhost:8000>

## Құрылымы

```
index.html, css/, js/        — бет (жинаусыз, тәуелділіксіз)
  js/app.js                  — мәзір, бөлімдер арасындағы ауысу
  js/viewer.js               — суреттерді сырғыту
  js/quiz.js                 — «… қайда?» ойыны
  js/audio.js, js/fx.js      — дыбыс, анимациялар, салют
content.json                 — барлық сөздер
assets/img, anim             — суреттер мен анимациялар (Noto Emoji)
assets/audio                 — сөздер, сұрақтар («… қайда?»), мақтау сөздері
assets/sounds                — жануарлар мен заттардың дыбыстары
tools/                       — суреттерді жүктеу, дауыс жазу, дыбыстарды қию
```
