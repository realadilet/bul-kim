# Бұл кім? — жануарлар қазақша

Интерактивная страница для малышей (2–4 года): на экране анимированное животное,
голос называет его по-казахски — «Маймыл!», «Арыстан!», «Түйе!». Вместо YouTube:
без рекламы, без автоперехода на чужие видео, работает офлайн.

## Как пользоваться

| Действие | Что происходит |
|---|---|
| свайп влево / вправо или большие стрелки | следующее / предыдущее животное (по кругу) |
| тап по животному | ещё раз называет, животное подпрыгивает, летят звёздочки |
| ▶ вверху | автопоказ: называет дважды и через ~6 сек листает сам |
| ▦ вверху | все животные сеткой, можно выбрать любое |
| ⛶ вверху | полный экран (Android, iPad, компьютер) |
| ← → пробел | управление с клавиатуры |

Ссылка на конкретное животное: `…/#maimyl`, `…/#tuie` и т.п. (id из `animals.json`).

### Советы родителям

- **Добавьте на главный экран** (Safari → «Поделиться» → «На экран Домой»; Chrome → «Установить приложение»).
  Откроется без адресной строки, а после первого запуска работает без интернета.
- **iPhone/iPad: «Гид-доступ»** (Настройки → Универсальный доступ → Гид-доступ), потом тройное нажатие боковой
  кнопки — ребёнок не выйдет из приложения.
  **Android: «Закрепление экрана»** (Настройки → Безопасность → Закрепление приложения).
- Звук на iPhone идёт даже при включённом беззвучном режиме (Safari 16.4+); проверьте громкость.

## Добавить или поменять животное

1. Найдите эмодзи на <https://googlefonts.github.io/noto-emoji-animation/> (там видно, какие анимированные),
   код — это часть URL вида `1f412`.
2. Добавьте строку в `animals.json`:
   ```json
   { "id": "shoshqa", "kk": "Шошқа", "ru": "свинья", "emoji": "1f416", "anim": true }
   ```
   `anim: false` — если анимации нет (тогда картинка мягко покачивается).
3. Скачайте картинку и сгенерируйте озвучку:
   ```bash
   pip install edge-tts      # нужен ещё ffmpeg
   python3 tools/build_assets.py                    # только новое
   python3 tools/build_assets.py --only qoi --force # переозвучить одно слово
   ```
   Голос и скорость — в начале `animals.json` (`kk-KZ-AigulNeural` женский, `kk-KZ-DauletNeural` мужской).
   Можно просто положить свою запись в `assets/audio/<id>.mp3` — например, голос мамы.
4. Закоммитьте и запушьте — GitHub Pages обновится сам.

## Локальный запуск

```bash
python3 -m http.server 8000   # и открыть http://localhost:8000
```

## Структура

```
index.html, css/, js/app.js   — сама страница, без сборки и зависимостей
animals.json                  — список животных (единственный источник правды)
assets/img/*.svg              — статичные картинки (Noto Emoji)
assets/anim/*.json            — Lottie-анимации (Noto Animated Emoji)
assets/audio/*.mp3            — озвучка
sw.js, manifest.webmanifest   — офлайн и установка как приложение
tools/build_assets.py         — скачивание картинок и генерация озвучки
```
